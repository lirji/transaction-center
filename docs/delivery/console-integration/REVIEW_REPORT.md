## 关键审查

- 生产只改变归因enabled的环境变量绑定和Compose配置；无数据库迁移、资金状态机或前端业务页面变更。
- 默认敏感开关关闭；Worker覆盖入口开关且无宿主端口，API关闭后台循环。
- 所有种子写入走生产服务及本地事务；SQL仅用于断言。重复种子检查业务号、行数、退款状态，浏览器同键重放后核对库存守恒。
- 测试身份绑定回环随机端口、RSA签名、精确redirect/client校验及S256验证；无生产JwtDecoder替换。测试身份与渠道可信输入不等同真实供应商验收。
- 测试类仅位于src/test/java；CI不读取deploy秘密文件，不执行真实审批或支付。真实联调禁用trace/HAR/令牌持久化。
- 页面没有新增批准退款按钮，真实浏览器明确断言不存在。

## 残余风险

远程Actions、外部Casdoor/支付/风控/审批/WMS仍需各自验收。测试随机空闲端口存在很小的绑定竞争，冲突会失败而不会复用外部实例。自动准入磁盘必须由部署方确认实际存储映射。
