# 裂变系列活动端到端交付追踪

## 最终目标与顺序

用户明确要求持续推进至裂变系列活动实现，不以交易中心局部模块完成为结束。当前已批准边界为直接邀请、注册／首单条件、固定券、双边及阶梯奖；后续具体规则以原裂变生产设计为准。

先完成交易中心内部，再改造现有营销、权益、风控、流程、对账和身份集成。前端实现由Cursor负责，本Agent维护接口／交接及后端验收；前端联调证据仍是最终验收依赖，不能省略。
