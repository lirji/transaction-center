# 商品查询缓存与热点SKU准入

原03-FINAL_PLAN第7节要求版本缓存、TTL抖动、单飞回源、负缓存、限量主库降级与热点SKU限流。本阶段处理这些内部能力；10,000 RPS、P99≤200ms、500订单RPS等原容量验收仍须使用原规模数据和指定环境实测，不能由功能测试宣称达标。价格最终仍以有效报价/订单快照为准。

## 商品展示查询

新增CatalogQueryService，只接会员商品列表和详情（含已发布SKU展示列表），管理员草稿和QuoteService/SkuService.published/CatalogPort.requireSku保持主库原路径。缓存不参与支付金额、商品当前可售、库存预占或退款判断。

CatalogCachePort由server Redis适配器实现，复用原指定dev_infra redis7（127.0.0.1:46379，容器infra-redis7:6379），客户端依赖版本跟随项目Spring Boot BOM。配置默认关闭，启用时必须指定环境前缀、专用ACL用户和凭据；不打印秘密，不依赖逻辑DB隔离。测试使用独立随机环境前缀和短TTL，不扫描或清空共享Redis键。

缓存键包含trade:<env>:<tenant>:catalog:<generation>:<kind>:<queryHash>。generation为租户目录发布代次随机UUID，不能在旧缓存仍存活时重用代次；目录代次键TTL大于最长数据TTL。数据保留原publishedRevision/version，不用草稿价格覆盖发布视图。每次发布/下架成功提交后异步轮换共享Redis代次，所有API实例下一查询都使用新代次。同步事务内不发Redis网络；任务提交失败、Redis故障或进程在提交后崩溃，最多由短TTL兜底，不把已经提交的发布伪装失败。旧回源只写其读取时的代次，不能写入后来代次。

命中返回不可变、经过形状/租户查询绑定校验的展示结果。详情不存在和空列表短负缓存；正TTL建议30秒加有限抖动，负TTL2秒加有限抖动。列表after/limit及SKU列表productId严格验证且纳入键，所有缓存值限制字节大小和条目数；拒绝无界查询、跨租户值或无效JSON。缓存底层按maxmemory/TTL治理，应用侧并发回源键数量和Redis在途请求都另设硬上限。

同进程同租户同查询只允许一个回源leader，其他请求等待同一有界结果；不同键的回源并发和速率也受独立预算约束。限流不是只设一个不受控ConcurrentHashMap。回源使用只读主库事务/查询超时，不在等待单飞或Redis时持有数据库连接。Redis不可用或损坏按同一主库预算降级；预算满返回503或429和Retry-After，不无限把流量导向资金主库。single-flight、负缓存和Redis故障模式需并发测试验证。

注册失效动作只能在数据库事务提交之后发送，使用容量固定的执行器且拒绝必须被捕获并记指标。不能在Spring afterCommit回调线程直接发网络并假设连接已经释放；异步线程不继承交易事务。Redis网络超时、并发容量和回源预算均可配置且有范围检查；功能关闭时仍对展示主库回源施加预算。

## 热点SKU新增预占

在InventoryService.reserve的Commands新业务lambda开头加入HotSkuAdmission，键为tenant/warehouse/sku。仅新预占受限制，已缓存的同键结果先重放；确认、可靠释放和退货回库不受该限制。每键并发上限、最大跟踪键数均有硬上限，超出立即返回429与Retry-After，不持数据库连接排队等待。槽位保持到整个外层事务提交/回滚，不能reserve方法一返回就提前释放。

同一事务再次访问相同SKU复用已持槽位，事务同步回调清理资源并移除无引用键；不同键按现有库存顺序办理，不增加分布式锁或库存桶。该预算为每API实例，需要结合副本数限制总准入，不能宣传为跨实例全局限流。数据库条件更新、唯一预占及原锁序继续承担不超卖正确性；库存桶仍要求基准不足证据后再考虑。

验证包括同SKU拒绝与异SKU隔离、提交/回滚释放、嵌套事务不早释放、相同事务不自锁、跟踪键满时有界拒绝、确认/释放/退货不被限制，以及缓存故障不能绕过资金主库判断。生产指标增加缓存命中/负命中/回源/拒绝/失效失败及热点准入拒绝，指标不使用原始会员或请求ID。

## 独立设计审查约束

generation缺失时SET NX随机UUID并读取实际赢家；轮换只写新随机值，代次永不主动复用。单飞键必须包含generation，否则新代次查询会复用旧代次尚未完成的回源。展示入口采用NEVER并在任何Redis或等待之前检查无实际事务；只有leader回源段开启独立主库只读事务，不沿用调用者RR快照。

HotSku事务复用表若绑定TransactionSynchronizationManager自定义resource，同步回调必须在suspend时解绑、resume时恢复。REQUIRES_NEW不会自动处理业务自定义资源，内层必须作为独立事务重新申请槽位；不能误复用外层槽位或提前释放外层许可。用真实事务管理器验证挂起/恢复和内外层回滚清理。
