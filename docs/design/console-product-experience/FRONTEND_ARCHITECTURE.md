# 交易中心控制台产品体验升级

从 `aef54aa` 接续。控制台由 React、Vite、React Router、TanStack Query 和现有样式组成。运营查看经营、异常和待办，商家视角查找和维护商品、交易与仓库，管理员核对渠道、准入、任务和操作日志。权限由原路由和 API 决定。

## 公共交互与样板

- 沿用现有颜色、文字与密度变量。主要任务保留独立路由，低频表格设置进入工具区，短表单与确认使用现有对话框。
- 表格呈现顺序服务于查找、核对和处置。保留字段，宽表在自身滚动区域显示。表格工具支持列可见性、密度及放大查看。可执行刷新依赖当前查询；关键业务号可复制。
- 游标分页以服务端游标为依据。每页条数进入有效查询及游标路径作用域；URL 列表保留条数，切换条数从首页读取。快速跳转只使用同一查询范围已有的真实游标。
- 日期输入使用北京时间和原有半开区间，沿用 90 天限制与精度。快捷时间转成真实起止值。选择器支持键盘和清晰的选中反馈，选项来自已有业务列表或枚举。
- 工作台使用实际期间汇总。订单指标进入相同期间的订单列表，资金指标进入同期间、同币种的明细。上期比较取相邻等长期间。已取样待办只展示实际样本。经营图、对账和异常状态各自表达读取失败与真实空态。
- 样板选择工作台、订单列表与详情、库存调整。基础交互在桌面 1440px、窄桌面 1024px、手机 390px 验证。

后续实现覆盖原有缺口。接口、页面及验收范围见[数据能力交付计划](../console-data-completion/PLAN.md)。

## 验收记录

- `pnpm lint`、`pnpm build`（含 TypeScript 检查）、`pnpm test` 均通过，单元测试 53 项。
- Chromium 接口契约测试通过 15 项。Firefox 和 WebKit 的兼容性抽查共 16 项通过，包含一次单独复验。18 个常规入口逐一检查 1440、1024 和 390px 下的页面布局，权限阻止入口和未知路由同时检查。
- 重点交互覆盖日期快捷筛选、键盘选择、游标缓存及跳转、页容量请求、刷新、列设置、显示密度、放大查看、编号复制、经营期间比较、汇总明细联动和实收抽屉。任务页面及详情另走诊断权限的联调场景。
- `scripts/verify-console-integration.sh` 使用隔离 MySQL、实际 Java API 和测试 OIDC，复验 10 项全部通过，覆盖登录与权限、资金汇总核对、页间一致性、会员冻结、退货验收、限流和跨租户隔离。
