# 交易中心控制台界面规范

基线为 `e097af4` 的 `frontend/apps/console`。路由定义在 `src/App.tsx`，权限导航在 `src/app/navigation.ts`。继续用单个 React、TypeScript、Vite 应用，复用 React Router、TanStack Query、Lucide、现有 UI 原语和 API 客户端。身份、字段验证、金额精度、北京时间、游标、版本与命令结果沿用现有契约。

## 导航与页面结构

- 运营由工作台查看受理、待办样本和期间经营数据，进入实际业务队列。商户和目录作业沿用会员、商品、库存和渠道入口。管理员沿用对账、运行、准入和日志的授权入口。
- 侧栏按任务分组，桌面持续可见，窄屏由菜单按钮展开。顶栏展示路径、租户和账户，并按现有权限提供模块搜索。进入深链时保留对象所在模块的路径。
- 列表使用标题、筛选、结果表与游标分页。快捷队列贴近查询结果，低频条件放入高级筛选，已应用条件仍可辨识。详情面包屑和商品返回按钮可回到进入详情时的列表查询。订单返回时还会定位到原订单。
- 详情使用业务摘要、明细和相关记录。主对象保留独立路由，便于查找与分享。短表单和高影响确认使用弹窗，长期作业与多段配置使用原路由内的独立分区。
- 继续由 TanStack Query 持有服务端数据，URL 持有现有查询参数，输入与弹层由页面维护。读取、无结果、权限拒绝、命令失败和确认结果使用共享状态样式。异步受理沿用原业务口径。

## 视觉与组件

- 白色工作面，冷灰画布、墨色正文、钴蓝主操作与当前入口。成功、待处理、失败各用低饱和背景与深色文字。
- 使用系统中文字体栈，表格正文 13px，主要控件 34px，页标题 25–28px。间距从 4px 起，表面细线分隔，弹层具有投影。宽屏使用可用空间，窄屏将横向滚动限定在表格。
- 表格按对象、状态、金额和时间组织。金额和数量右对齐，长字符串可换行或滚动查看，关键编号保留链接。仅在明显提升横向浏览时固定识别或操作列。分页反馈显示当前页行数和接口观察时间。
- 表单用可见标签、必填标识和字段级帮助。页内复杂配置可双列，简短确认使用单列。主按钮集中在当前任务区，次操作减弱，破坏性的确认独立强调。
- 设计方向来自本次需求。先用订单列表、详情及商品草稿/SKU 验证，随后覆盖下表。验收视口为桌面 1440px、较窄桌面 1024px 和手机 390px。

## 页面与交互覆盖

| 页面 | 主任务与关联交互 |
| --- | --- |
| 工作台 | 交易受理、实时队列样本、期间汇总及资金明细 |
| 会员、条款、商户 | 名单与会员状态确认、风险评估、条款发布、商户创建及冻结 |
| 商品与商品详情 | 搜索、创建草稿、发布状态、目录与 SKU 编辑、发布及下架确认 |
| 仓库与库存 | 余额、仓库、流水、创建仓库、盘点调整与确认 |
| 订单与订单详情 | 高频及高级筛选、摘要、关联记录分区、复制、履约入口、列表查询恢复 |
| 支付与支付详情 | 列表及支付尝试、状态筛选和实收关联 |
| 实收与实收详情 | 异常队列、金额与渠道、确认和支付时间 |
| 报价与报价详情 | 筛选、金额、有效期和冻结商品 |
| 退款与退款详情 | 队列、政策表单、审批截止、分项和操作日志 |
| 退货与履约 | 退货查询、详情、申请、验收，履约声明及确认 |
| 支付渠道 | 渠道登记、绑定状态与配置字段 |
| 任务与任务详情 | 授权入口、运行状态、租约、重试时间等详情 |
| Outbox 与对账 | 队列和恢复记录、受控重放及原渠道只查单 |
| 准入与操作日志 | 受理配置及确认、对象与时间筛选、继续分页 |
| 登录、回调、权限拒绝与未找到 | 认证入口、状态说明与回退 |

## 后续契约议题

商品图片、可展示店铺名称、批量变更、跨页导入导出和列表全量统计需先确认数据投影、权限及结果契约。本轮使用已提供的商品、商户、仓库及资金字段。
