# 交易控制台数据能力交付计划

## 验收切片

| 切片 | 交付与验收 |
| --- | --- |
| 列表 | 逐一盘点使用分页的列表和明细。准确总量及页内记录来自同一只读快照，沿用已有筛选、顺序、权限。跨页读最新数据，超出末页回到有效页。旧游标、既有应用及旧 URL 继续可读。 |
| 经营 | 按北京时间自然日归组，沿用订单创建与资金本地确认的业务时间。订单状态是查询时状态，已付转化以窗口内有应付额的创建订单为分母、其中截至窗口结束有真实支付为分子。真实事实与汇总勾稽，覆盖部分首尾日、零数据、退款和跨租户。 |
| 库存与目录 | 区分可用量为零与低于已配置补货阈值。阈值按租户、仓库和 SKU 维护。商品图片沿用权威资产引用与既有安全约束。 |
| 批量处理 | 按明确对象重用既有授权、幂等和单项版本约束。导入、导出有明确字段白名单、批量上限及逐项结果。资金、审批和发放按原有权威入口执行。 |
| 跨系统 | 核对商城店铺、营销活动和预算、权益发放的权威接口、audience、租户及门店授权。来自交易绑定的记录只代表交易侧覆盖。 |
| 交付 | 验收表逐项更新，真实 MySQL / OIDC 联调、前端构建及 CI。以同一 Git SHA 构建两张镜像并在现有本机 Docker 验证，保留回退。 |

## 技术选型与影响

分页复用 Java、MyBatis XML、管理查询限流和 React。新页码查询是显式入口，列表和计数共享原筛选片段，避免通用 SQL 改写、枚举列名和前端统计。使用有界的 LIMIT/OFFSET 和查询超时，初期沿用实际租户索引，记录大租户深页成本。任务和下钻附加权限由原服务和路由规则保护。

统计按现有交易事实做只读聚合，通过出现时间将订单与资金分别分桶，沿用原币种窗口和金额精度。同一事务给出状态分布和日报，便于对照。独立领域采用权威 HTTP 契约与身份边界，固定试点绑定只用于已持久化的实际交易范围。

## 已实现的契约与页面

| 入口 | 实现 |
| --- | --- |
| 订单 | 既有编号分页，新增筛选结果 CSV 同快照导出。单次上限 50,000 行，查询超时或超量会整体失败。 |
| 支付、实收、退货、报价、退款、任务 | 编号分页，精确搜索、时间窗口与诊断权限沿用原列表。 |
| 商品、库存、会员、渠道、条款 | 编号分页，商品支持 HTTPS 展示图、批量导入草稿及上架／下架，库存支持真实缺货与独立版本的补货规则。 |
| 仓库、库存流水、SKU、支付尝试、退款日志 | 编号分页或分页容量补齐，保留父资源授权及原游标契约。 |
| Outbox 发布与任务、对账差异与处置、操作日志 | 分别独立页码和全量计数，已授权筛选范围内读取。 |
| 工作台 | 北京时间日分组、当前订单状态、同批创建订单转化、资金事实编号分页。支持打开同期间、同币种状态筛选。 |
| 来源工作台 | 按用户确认的独立授权方式接入。商城、营销、权益入口由配置提供，交易端的试点绑定及已验真预算回执沿用业务证据权限。实际活动状态、权益发放、预算消耗和目标数据由各自来源展示。 |

批量导入使用 JSON 草稿列表，一次最多 100 行。批量上下架复用既有命令和乐观版本，按对象稳定顺序处理，任一项失败会回滚整批。请求成功返回逐项结果，同幂等键重放返回同组结果。新查询沿用管理限流和超时。排序与计数在一次只读数据库快照内一致，跨请求重新观察实际业务变化。

## 验收记录

- Java 管理参数、OpenAPI 映射、实际商城订单与预算回执绑定共 9 项通过。普通管理员与其它交易租户无法使用诊断权限取得关联记录。
- 前端 Lint、TypeScript、构建、53 项单测和 16 项 Chromium 检查通过。真实 Java API／MySQL／OIDC 联调 13 项通过，含批量版本失败后的整批回滚、图片存取、独立补货配置、CSV 以及全量日趋势勾稽。
- 本机现有 V053 数据以副本演练 V054。产品、库存、订单及审计行数保持一致，旧版本 Flyway 校验通过。商城与营销入口返回可用页面，权益运营台依赖来源服务在所配置地址运行。
